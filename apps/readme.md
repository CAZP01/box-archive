# Apps — Box Archive

Folder ini diperuntukkan bagi aplikasi antarmuka pengguna dan server API utama:

- **Frontend (`web/`)**: *Progressive Web App* (PWA) berbasis React.js untuk Mahasiswa, Dosen, dan Admin.
- **Backend (`backend/`)**: REST API berbasis Python (FastAPI) yang mengorkestrasi jadwal kelas, status perangkat IoT, pemanggilan `services/ai_pipeline`, penyimpanan database (Supabase), serta layanan RAG Chatbot.
